# 🚀 EventRadar: Умная платформа для IT-мероприятий
Единый минималистичный хаб IT-мероприятий с ИИ-подбором и геймификацией.

## 🎯 Проблема и Аудитория
**Целевая аудитория:**
- Студенты Software Engineering и других IT-направлений (от новичков до выпускников).
- Организаторы IT-мероприятий (митапы, хакатоны, лекции).

**Проблема:**
- Информационный шум и расфокус.
- Ивенты разбросаны по разным соцсетям (которые студенты часто удаляют для "дофаминового детокса").
- Нет удобного фильтра по уровню навыков и технологическому стеку пользователя.

## 💡 Наше Решение
Платформа в формате **умной ленты**, использующая:
- **Геймификацию** для мотивации, вовлечения и построения привычки.
- **Искусственный интеллект** для идеального подбора мероприятий под профиль каждого студента.
- **Минимализм** для глубокой фокусировки на самом главном.

## 🛠 Архитектура и Технический Стек
**Надежно, быстро, современно:**
- **Frontend:** React.js / HTML+CSS+JS
- **Backend:** Node.js + Express
- **База данных и Auth:** Firebase (быстрый и безопасный вход в 1 клик через Google)
- **ИИ-интеграция:** API OpenAI / Gemini для обработки промптов и генерации рекомендаций

## 🎨 UI/UX Дизайн и Интерфейс
**Никакого визуального мусора. Только функциональность и эстетика.**
- **Стиль:** Минимализм, профессиональный современный дизайн (по аналогии с Threads), формат бесконечной ленты.
- **Палитра:** 
  - Чистый белый фон 
  - Глубокий черный текст и границы
  - Энергичный оранжевый (акцентный цвет для Call-to-Action кнопок и элементов геймификации)

## 🧑‍💻 Пользовательский путь: Студент
1. **Быстрый старт:** Авторизация в один клик через Google.
2. **Шахматный онбординг:** Выбор направления (Full-stack, Дизайн, Менеджмент и др.) и уровня (Новичок, Любитель, Профи).
3. **Лента (Feed):** Просмотр минималистичной ленты актуальных постов от организаторов.
4. **AI-Магия:** Оранжевый блок «AI-Наставник» персонализирует сложное описание ивента в короткий инсайт под конкретного студента.
5. **Действие:** Клик по кнопке «Иду (+50 XP)» запускает механизм получения опыта.

## 📢 Пользовательский путь: Организатор
1. **Создание поста:** Максимально простая форма (Название, Описание, Теги). Без лишних полей.
2. **Beginner Friendly:** Специальный чекбокс для мероприятий, открытых и подходящих для новичков.
3. **Публикация:** Сразу после публикации ИИ-алгоритм мгновенно начинает мэтчить пост с релевантными студентами в их лентах.

## 🎮 Геймификация
**Игровые механики, работающие в единой связке:**
- **Баллы (XP):** Начисляются за успешный онбординг и регистрацию на хакатоны/митапы.
- **Шкала прогресса (XP Bar):** Всегда находится на виду в верхней шапке профиля, визуализируя прогресс до следующего ранга.
- **Уровни (Ранги):** Шахматная система прогрессии: *Новичок → Любитель → Профи*.
- **Награды:** Повышение уровня открывает доступ к эксклюзивным и закрытым "VIP" митапам.

## 🧠 AI-Наставник и Инженерия Промптов
**ИИ делает сложные вещи простыми и работает в двух режимах:**

**1. Подбор мероприятий (Для ленты)**
- ИИ выступает как *дружелюбный карьерный наставник*.
- Анализирует скучное описание ивента и выдает короткую выжимку (макс. 4 предложения): цепляющий заголовок, почему это полезно для текущего уровня пользователя, какой главный навык можно получить и мотивирующий призыв.

**2. Рефлексия (После ивента)**
- ИИ выступает как *IT-коуч*.
- Поздравляет студента с получением баллов XP и задает один открытый вопрос для рефлексии и самоанализа полученного опыта (макс. 2 предложения).
